========================================
  GAME SITE - STEP BY STEP
========================================

WHAT'S IN THIS FOLDER
---------------------
index.html      The gallery page. Don't edit it.
games.json      The list of games. THIS is the file you edit.
games/          One HTML file per game.
covers/         One picture per game.

A sample game (Pong) is already set up so you can see it working.


----------------------------------------
PART 1: TEST IT ON YOUR COMPUTER
----------------------------------------

Step 1. Open index.html in your browser.
Step 2. You should see one tile: Pong.
Step 3. Click it. Pong opens and plays.

If you see "Could not load games.json", skip to PART 4.


----------------------------------------
PART 2: PUT IT ONLINE (GitHub Pages)
----------------------------------------

Step 1.  Go to github.com and sign in.

Step 2.  Click the + in the top right, then "New repository".

Step 3.  Name it:  games
         Set it to:  Public
         Click "Create repository".

Step 4.  On the next page click "uploading an existing file".

Step 5.  Drag in index.html, games.json, and the games and
         covers FOLDERS (drag the folders themselves).

Step 6.  Click "Commit changes".

Step 7.  Click the "Settings" tab at the top of the repo.

Step 8.  In the left sidebar, click "Pages".

Step 9.  Under "Branch", choose:  main   and   / (root)
         Click "Save".

Step 10. Wait about 1 minute, then reload that page.
         It will show your address, like:
         https://YOURNAME.github.io/games/

Step 11. Open that address. Your site is live.


----------------------------------------
PART 3: ADD A NEW GAME
----------------------------------------

Do this every time you want to add a game.

Step 1.  Get the game's HTML file. Rename it something
         simple with no spaces, like:  snake.html

Step 2.  Get a picture for it. Rename it to match:  snake.png

Step 3.  In your GitHub repo, open the "games" folder.
         Click "Add file" > "Upload files". Upload snake.html.
         Click "Commit changes".

Step 4.  Open the "covers" folder.
         Click "Add file" > "Upload files". Upload snake.png.
         Click "Commit changes".

Step 5.  Go back to the main repo page. Click games.json.

Step 6.  Click the pencil icon (top right) to edit it.

Step 7.  Add your game to the list. It will look like this
         when you have two games:

[
  {
    "name": "Pong",
    "img": "covers/pong.png",
    "url": "games/pong.html"
  },
  {
    "name": "Snake",
    "img": "covers/snake.png",
    "url": "games/snake.html"
  }
]

         THE THREE RULES:
         - Put a comma after the } of every game EXCEPT the last one.
         - Every line inside the { } needs its quotes.
         - The file names must match exactly, capital letters included.

Step 8.  Click "Commit changes".

Step 9.  Wait about 1 minute, reload your site. New tile is there.


----------------------------------------
PART 4: PUT IT ON YOUR WEEBLY SITE
----------------------------------------

Option A - a link (easiest):
  Step 1. Edit your Weebly page.
  Step 2. Add a Button or Text element.
  Step 3. Link it to https://YOURNAME.github.io/games/
  Step 4. Set it to open in a new window. Publish.

Option B - show it inside the page:
  Step 1. Edit your Weebly page.
  Step 2. Drag in an "Embed Code" element.
  Step 3. Click it, then "Edit Custom HTML".
  Step 4. Paste this, with your own address in it:

  <iframe src="https://YOURNAME.github.io/games/"
          style="width:100%;height:800px;border:0"></iframe>

  Step 5. Click outside the box. Publish.


----------------------------------------
IF SOMETHING BREAKS
----------------------------------------

"Could not load games.json"
  -> You opened index.html by double-clicking it, and your
     browser blocks the file. This is normal and it will
     work fine once it's on GitHub. To test locally anyway,
     open a terminal in this folder and run:
       python3 -m http.server
     then visit  http://localhost:8000

A tile shows a blank gray box
  -> The picture name in games.json doesn't match the real
     file name in covers/. Check spelling and capitals.

Clicking a tile gives "404"
  -> The "url" in games.json doesn't match the real file
     name in games/. Check spelling and capitals.

Nothing shows up at all
  -> There's a typo in games.json. Usually a missing comma
     between games, or a comma after the LAST game.
     Paste the file into jsonlint.com to find it.
